JENIS PENGEMBANGAN

Bahasa Pemrograman Native vs Hybrid

Aplikasi Native

Khusus Satu Platform Spesifik

Dibuat menggunakan bahasa resmi dari penyedia platform OS. Memiliki akses penuh ke fitur hardware fisik.

  • Performa sangat tinggi & responsif
  • Akses sensor kamera & GPS maksimal
  • Biaya & waktu pembuatan lebih tinggi
Contoh Teknologi:
Kotlin (Android) Swift (iOS)

Aplikasi Hybrid

Satu Kode untuk Banyak Platform

Menggunakan teknologi web atau framework multiplatform. Sekali tulis kode, bisa dijalankan di Android & iOS.

  • Hemat biaya dan efisiensi waktu
  • Pemeliharaan kode lebih terpusat
  • Performa sedikit di bawah Native
Contoh Teknologi:
Flutter (Dart) React Native
KLASIFIKASI BAHASA

Bahasa Pemrograman Berdasarkan Platform

1. Platform Web

Berjalan di dalam peramban web (browser). Tidak memerlukan instalasi khusus di perangkat pengguna.

HTML, CSS, JavaScript
PHP, Python, Node.js

2. Desktop & Khusus

Berjalan langsung di atas OS komputer (Windows/Mac/Linux) atau mesin kasir & ATM.

C++, C#, Java
Python (PyQt), Electron

3. Mesin / Hardware

Berinteraksi langsung dengan sirkuit fisik, mikroprosesor, IoT, atau sistem robotik.

Assembly (Low-Level)
Bahasa C / Embedded C
STRUKTUR SISTEM

Arsitektur: Monolith vs Microservices

Monolithic Service

Seluruh modul aplikasi (database, UI, bisnis logika, autentikasi) digabung menjadi satu kesatuan unit besar.

[ Satu Aplikasi Raksasa ]
User Modul
Payment
Notifikasi

Kelebihan: Mudah dibangun di awal untuk tim kecil.

Kekurangan: Jika 1 fungsi rusak, seluruh aplikasi bisa tumbang.

Microservices

Aplikasi dipecah menjadi layanan-layanan kecil independen yang saling berkomunikasi melalui API.

Service User
Service Payment
Service Notif

← Terhubung via API Gateway →

Kelebihan: Fleksibel, dapat dikembangkan secara terpisah.

Kekurangan: Konfigurasi awal dan jaringan lebih rumit.

STRUKTUR UTAMA

Pengenalan HTML (HyperText Markup Language)

HTML bukanlah bahasa pemrograman berlogika (seperti C++ / Python), melainkan Bahasa Penanda (Markup Language) untuk menyusun kerangka halaman web.

Anatomi Tag HTML:

<p class="teks"> Halo Dunia </p>
Tag Pembuka + Atribut Isi Konten Tag Penutup
index.html 
<!DOCTYPE html>
<html>
  <head>
    <title>Web Pertamaku</title>
  </head>
  <body>
    <h1>Selamat Datang!</h1>
    <p>Ini paragraf pertama saya.</p>
  </body>
</html>
DESAIN & STYLE

Pengenalan CSS (Cascading Style Sheets)

CSS bertugas menghias tampilan elemen HTML agar menarik. Mengatur warna, tata letak, jarak, ukuran font, hingga animasi.

Aturan Penulisan Sintaks CSS:

h1 {
  color: #3b82f6;
  font-size: 24px;
}
Inline CSS
Di dalam atribut HTML
Internal CSS
Tag <style> di head
External CSS
File style.css terpisah
Simulasi Perubahan CSS:

Elemen Judul Web

Tampilan dapat diubah secara instan dengan CSS.

METAFORA PEMAHAMAN

Analogi Triad Pemrograman Web

HTML

Rangka & Tulang Manusia

Memberikan struktur fisik dasar. Tanpa CSS/JS, halaman web hanya berupa teks hitam-putih polos bertingkat.

CSS

Pakaian, Warna & Gaya

Memberikan estetika visual: warna kulit, Pakaian, perhiasan, dan tata letak gaya tubuh agar memikat mata.

JavaScript

Otot, Saraf & Otak

Memberikan kemampuan bergerak, berpikir, merespons klik, animasi dinamis, dan pemrosesan data.
